# Skill: Add an API Endpoint
1. Read the feature requirements and backend steering.
2. Define request/response behavior and error cases.
3. Add Marshmallow schema validation.
4. Implement business logic in service.py.
5. Keep routes.py thin and apply authentication/authorization.
6. Add unit/API tests for success, validation, unauthenticated, and unauthorized cases.
7. Export OpenAPI and update traceability.
8. Review the diff and record refinements.
