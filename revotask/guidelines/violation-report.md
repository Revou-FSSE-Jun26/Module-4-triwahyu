# Guideline Violation Report

AI-generated code was reviewed against `guidelines/` before anything was kept. This report lists the violations that were found, the rule each one breaks, and the fix that was applied. Every entry was confirmed in real code: line numbers for the scaffold come from the saved baseline snapshot, and the rest were caught in review of first drafts produced during this work.

**How violations were found**
1. Read each generated file against the rule list for its layer.
2. Ran `python scripts/check_guidelines.py` against the untouched scaffold: **11 of 28 checks failed (47 findings)**. The same checks pass 28/28 on the refined repo (see `before-after-comparison.md`).
3. Ran the tests, linters and Playwright, and treated any failure as a possible violation. Several entries below were found this way.

- `backend/.env.example:2` set `FLASK_ENV`, which Flask 2.3+ ignores. Replaced by `APP_ENV`.
